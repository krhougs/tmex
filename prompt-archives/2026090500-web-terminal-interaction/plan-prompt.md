# 用户需求

用户希望网页终端获得与原生终端接近的体验：系统惯性、平滑滚动、右键／长按菜单。随后明确指出当前画面按整行跳动，缺少显式 GPU 渲染管线，要求继续实现。

背景：网页使用 Ghostty VT WASM + Canvas 2D；原生宿主使用原生 Ghostty VT 和 GPU 渲染。保留网页内核与终端协议，只调整网页渲染和交互。菜单暂按终端内菜单实现，用户未要求强制使用系统原生菜单。

约束：工程工作面为父仓库的 `.worktrees/web-terminal-interaction`，本仓分支 `vibex/web-terminal-interaction`；不改变原生终端默认路径，不触碰生产服务。主 Agent 负责架构、Review 和最终验收；subagent 只承担明确划定的实现任务。

后续用户指令：“继续”。沿用同一工作区和分支完成实现、验证及收尾，不包含合并或部署。

用户后续反馈：终端滑动到字高的一半时整行消失，快速滑动能观察到几行字的空缺。修复范围为当前网页终端滚动回归，并同步到已授权的独立开发环境。

用户后续反馈：看不到光标闪烁，终端在最下方时没有跟随新内容滚动。

用户再次反馈：光标仍没有闪烁，且滑动上去再滑下来就消失。
