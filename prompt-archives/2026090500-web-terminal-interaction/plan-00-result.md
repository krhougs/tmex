# 实施结果

已完成网页终端的 WebGL2 渲染、浏览器原生连续滚动和终端内右键／长按菜单。工作区保持在父仓库 `.worktrees/web-terminal-interaction`，父仓分支 `feat/web-terminal-interaction`，本仓分支 `vibex/web-terminal-interaction`。已部署至独立测试环境；用户已授权将本轮改动提交并合入集成分支。

## 实现

- 新增 WebGL2 批量绘制管线与有界字形纹理图集。首次字形光栅化使用 Canvas 2D，后续屏幕绘制由 GPU 合成；保留中文、emoji、连字、字符约束、选择、光标、链接下划线和 Kitty 图像。初始化失败或上下文丢失时恢复 Canvas，并保留诊断原因。
- 普通历史视口由真实 overflow 容器滚动。浏览器 scrollTop 保留亚行像素，Ghostty 仅在跨行时更新逻辑视口；额外绘制边缘一行。避免每帧回写 scrollTop 打断浏览器滚动；历史前插保持内容与亚行偏移。
- 触摸滚动交给浏览器原生惯性；保留 TUI 鼠标上报、alternate scroll 与长按选择。长按选择释放后打开菜单，桌面支持右键、Shift+F10 和菜单键。菜单包含复制、粘贴、全选及命中链接操作，复用现有剪贴板和文件粘贴边界。
- 原生 App 默认终端路径不变；使用共享网页终端的路径获得上述改进。

## 滚动空行回归修复（2026-09-05）

用户反馈半行滚动时整行消失、快速滚动出现数行空缺。原画布只有底部一行预绘制，浏览器滚动先于下一帧时覆盖不足。改为上下各约一屏缓冲，绘制完成后同步移动画布；逻辑视口保持原行数，选择、链接和 Kitty 图片映射到带缓冲的绘制坐标。

- Chrome WebGL2 与 Canvas 回退各验证 6 个场景：向上／下半行、6.5 行，以及历史顶部／底部边界。刻意暂停 rAF 让浏览器先滚动，恢复绘制前后截图逐像素相同；点击命中行号正确。
- 新增真实 WASM 回归测试，保护跨视口预读取的行连续性、视口恢复与后续输出。终端相关测试 287 项通过，772 次断言；webapp 类型检查和生产构建通过。
- 本轮未复测 WebKit，当前 Python Playwright 所需的 WebKit 二进制未安装。
- 修复同步至独立测试环境 `http://192.168.89.180:28792/` 的源码，由 Vite 加载。

## 底部跟随与光标回归修复（2026-09-05）

浏览器复现确认：程序设置 scrollTop 后的延迟 scroll 事件，与下一批 VT 输出交错，会把已前进的 Ghostty 视口拉回旧行，随后光标落到视口外、闪烁停止。记录最近处理／设置的实际 scrollTop，位置未变化的迟到事件不再修改逻辑视口；真实用户位移继续按原路径处理。

- 新回归测试在修复前出现多余的 -1 行回滚，修复后通过，并覆盖用户上翻后保持半行位置。
- Chrome WebGL2 实测连续 100 批输出保持底部，手动上翻后 10 批输出不改变历史位置，回到底部后恢复跟随且光标可见。
- 闪烁模式下截图差异仅为光标矩形，确认真实像素亮灭；沿用终端指定的闪烁／常亮协议。
- 288 项终端测试、778 次断言通过，webapp 类型检查及生产构建通过。修复同步到独立测试环境 28792 端口。
