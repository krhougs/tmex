# 网页终端 GPU 渲染与连续滚动实施计划

目标：在保留 Ghostty WASM、历史分页、TUI 鼠标协议、输入法和文件粘贴能力的前提下，提供显式 GPU 渲染、像素级连续滚动、浏览器原生惯性、右键／长按操作菜单。

## 方案与边界

- 新增 WebGL2 渲染器，沿用现有字形约束、连字、颜色、字体度量语义；字形首次光栅化后存入有界纹理图集，屏幕绘制通过 GPU 批量合成。初始化／上下文失效时回退现有 Canvas，并暴露真实 renderer kind。
- 真实 `overflow` 容器承担普通历史视口滚动，像素 scrollTop 与整行 Ghostty viewport 分离；画面边缘预绘制避免半行留白。历史前插保持当前内容锚点，输出贴底只在原本贴底时执行。
- TUI 鼠标上报与 alternate scroll 继续产生现有协议输入，不变成终端本地滚动；移动端长按本地选择保留，菜单共用产品组件。菜单支持复制、粘贴、全选与命中的链接操作，失败沿用现有剪贴板／上传边界。
- 备选方案：手写惯性曲线不具备系统手感；整屏 Canvas 上传到 GPU 仍保留主要逐帧 CPU 开销；全面 DOM 渲染扩大范围，均不采用。

## 实施

1. 在 `packages/ghostty-terminal/src/` 新增 WebGL2 renderer 和纹理缓存。复用或最小提取 `canvas-renderer.ts` 的绘制类型及纯函数。保留 Canvas 行为作为恢复路径。
2. 在 `terminal.ts` 建立原生滚动容器、像素位置、视口预绘制与命中坐标一致性；维护 reset、resize、历史前插、持续输出、模式切换时的滚动状态。在 `types.ts` 暴露所需交互方法。
3. 调整 `terminal-ui/src/components/useMobileTouch.ts`，普通历史滚动让浏览器处理，TUI 路由和长按选择继续有效；调整 `Terminal.tsx`，接入右键／长按菜单及现有复制、文件粘贴和链接处理。
4. 主 Agent 检查真实 diff 和调用链。复跑相关 Ghostty／terminal-ui 测试和 webapp TypeScript／构建。在临时浏览器页面验证 GPU 实际启用、亚行滚动、惯性、历史拼接、选区与菜单、TUI 路由、WebGL 丢失回退。临时页面和脚本只放 build 或系统临时目录。

## 验收

- 支持 WebGL2 的真实浏览器报告 `webgl`，字形从纹理图集合成，不通过整屏 Canvas 位图每帧上传伪装 GPU 渲染。
- 小于一行的滚动位移也改变可见位置；普通触摸松手继续系统惯性；滚动时无明显底边空行。
- 历史前插、回到底部、resize 与 TUI 鼠标模式不串行号或误发输入。
- 右键／长按菜单可用，复制内容与选择一致，粘贴沿用风险处理，菜单关闭后焦点恢复合理。
- GPU 不可用或 context lost 时恢复到可用终端；源码检查、相关测试和生产构建通过。

长期测试只保护新增的滚动状态／渲染恢复／交互协议边界，不为样式和一次性诊断增加永久测试。
